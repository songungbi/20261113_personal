작가 포트폴리오 웹사이트

1. index.html 파일을 브라우저에서 열면 시작합니다.
2. 같은 폴더에 about.html, works.html, guestbook.html, style.css, script.js, assets 폴더를 함께 보관해야 합니다.
3. 이름, 약력, 작품은 임시 예시 콘텐츠입니다. HTML 파일에서 바꾸세요.
4. 방명록은 localStorage 방식 데모입니다. 실제 방문자 사이에서 공유되는 게시판을 운영하려면 서버/DB 또는 외부 서비스 연동이 필요합니다.
5. 구글 웹폰트는 인터넷 연결이 없는 경우 기본 글꼴로 표시됩니다.
